## About the project

“Should I Really?” is the working title of a team project developed during the Apple Developer Academy journey.

The product premise, target users, feature set, and final project story are still awaiting confirmation from the team. This README intentionally describes the repository’s current state rather than filling those gaps with assumptions.

## Current state

The repository currently contains:

- A SwiftUI app entry point
- A `ContentView` scaffold used for the first app screen
- An asset catalog
- An Xcode project configured for an iOS 26.5 deployment target

The app behavior and product documentation will be expanded as the team’s direction is finalized.

## Getting started

### Requirements

- macOS with Xcode 26.6 or later
- An iOS simulator or connected device

### Run locally

1. Clone the repository:

   ```sh
   git clone https://github.com/deusgvrl/should-i-really.git
   cd should-i-really
   ```

2. Open `should-i-really.xcodeproj` in Xcode.
3. Select the `should-i-really` target and a simulator or connected device.
4. Build and run.
